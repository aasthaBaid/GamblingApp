# Gambling Management System 🎰

This project is a Python-based Gambling Management System developed using Object-Oriented Programming concepts and database connectivity. The system allows users to manage gamblers, create betting sessions, place bets, track wins and losses, and generate reports. It is designed as a menu-driven console application where users can easily interact with different gambling operations. 

The project includes features such as gambler creation, betting preference management, session handling, and betting validation. Users can start, pause, resume, and end gambling sessions while maintaining proper balance limits and betting thresholds. The system also validates probabilities and stake amounts to ensure safer and controlled betting operations.

Different service modules are used to separate functionalities like gambler management, session management, bet handling, reporting, and input validation. This makes the project modular, organized, and easy to maintain. The application also generates reports showing session summaries, total wins, losses, and overall gambler statistics.

### Technologies Used

* Python
* MySQL / SQL
* OOP Concepts
* Decimal Module

### Main Features

* Create and manage gamblers
* Set betting preferences
* Start and manage betting sessions
* Place bets with validation
* Track wins and losses
* Generate gambler reports
* Menu-driven user interface
